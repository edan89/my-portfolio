# Professional Data Portfolio

A premium, interactive portfolio website designed to showcase skills in **Data Engineering**, **AI Development**, and **Full-Stack Web Development**.

## 🚀 Overview

This portfolio is built with a focus on high-performance animations, clean aesthetics, and professional presentation. It features a custom-integrated Webflow-style interactive UI, optimized for recruiters and technical stakeholders.

## 📂 Project Structure

The project follows professional web development standards for file organization:

```text
Project_06_My_Portafolio/
├── assets/
│   ├── css/           # Stylesheets (main.css)
│   ├── js/            # JavaScript libraries (jQuery, GSAP, Webflow)
│   ├── images/        # Optimized images, logos, and favicons
│   ├── fonts/         # Local font files
│   └── docs/          # Career documents (resume.pdf, certificates/)
├── index.html         # Main entry point
└── README.md          # Project documentation
```

## 🛠️ Key Technologies

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Animations:** [GSAP](https://gsap.com/) (GreenSock Animation Platform) for high-end motion graphics.
- **Interactivity:** jQuery & Webflow-based interaction engine.
- **Design:** Modern typography, glassmorphism, and responsive layouts.

## 🔧 Local Development

To view the project locally:

1. Clone the repository or download the files.
2. Open a terminal in the project root.
3. Start a local server (to ensure all interactive elements and scripts load correctly):
   ```bash
   python -m http.server 8080
   ```
4. Open [http://localhost:8080](http://localhost:8080) in your web browser.
